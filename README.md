# Indian Loan Starter Kit

Create a complete frontend-only website boilerplate

for a premium Indian loan provider.

Services:

- Home Loan

- Personal Loan

- Business Loan

- Overdraft Facility

Generate:

- Homepage

- Four loan detail pages

- About Us

- Contact Us

- Responsive navbar and footer

- Loan enquiry form UI

- Modern 3D-inspired visual design

- Smooth animations

Use React, TypeScript, Tailwind CSS, and

Framer Motion.

Do not implement backend, authentication,

database, or API integrations.

Generate clean, reusable components

that I can download and continue coding

in VS Code.

Do not include credit cards, blogs,

or unrelated financial products.
